# NFA テストケース

このディレクトリには、正規表現から非決定的有限オートマトン (NFA) を生成するプログラムのテストケースが含まれています。各テストケースは、入力となる正規表現 (`<number>-in.txt`) と、それに対応するプログラムの出力 (`<number>-out.txt`) のペアで構成されています。

以下のテストケースが含まれています。

- **1-in.txt / 1-out.txt**:
  - 正規表現: `a`
  - テスト意図: 単一の文字リテラルに対する NFA 生成をテストします。

- **2-in.txt / 2-out.txt**:
  - 正規表現: `ab`
  - テスト意図: 2つの文字リテラルの連結に対する NFA 生成をテストします。

- **3-in.txt / 3-out.txt**:
  - 正規表現: `a|b`
  - テスト意図: 2つの文字リテラルの選択に対する NFA 生成をテストします。

- **4-in.txt / 4-out.txt**:
  - 正規表現: `a*`
  - テスト意図: 単一の文字リテラルに対するクリーネ閉包の NFA 生成をテストします。

- **5-in.txt / 5-out.txt**:
  - 正規表現: `(a|b)*`
  - テスト意図: 選択とクリーネ閉包を組み合わせた正規表現に対する NFA 生成をテストします。括弧の扱いも含まれます。

- **6-in.txt / 6-out.txt**:
  - 正規表現: `a(b|c)`
  - テスト意図: 連結と選択を組み合わせた正規表現に対する NFA 生成をテストします。括弧の扱いも含まれます。

- **7-in.txt / 7-out.txt**:
  - 正規表現: `a*b`
  - テスト意図: クリーネ閉包と連結を組み合わせた正規表現に対する NFA 生成をテストします。

- **8-in.txt / 8-out.txt**:
  - 正規表現: `\0`
  - テスト意図: NULL 文字リテラルに対する NFA 生成をテストします。

- **9-in.txt / 9-out.txt**:
  - 正規表現: `\e`
  - テスト意図: 空遷移文字リテラルに対する NFA 生成をテストします。

これらのテストケースは、正規表現の基本的な演算子が正しく NFA に変換されるかを確認することを目的としています。
